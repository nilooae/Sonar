# 🚀 Sonar Rock vs Mine Prediction

Machine Learning project for classifying sonar signals as **Rocks** or **Mines** using Python and Scikit-learn.

## 📌 Project Overview

This project uses the famous **Sonar Dataset** to build a machine learning classification model capable of identifying whether an object detected by sonar is:

* 🪨 Rock
* 💣 Mine

The notebook walks through the complete ML workflow including:

* Data loading
* Data preprocessing
* Exploratory analysis
* Train/Test splitting
* Model training
* Prediction
* Model evaluation

---

## 🛠️ Technologies Used

* Python
* NumPy
* Pandas
* Scikit-learn
* Jupyter Notebook

---

## 📂 Dataset Information

The dataset contains sonar signals bounced off different surfaces.
Each sample consists of numerical features representing signal energy values at different frequencies.

Target Labels:

* `R` → Rock
* `M` → Mine

---

## 🤖 Machine Learning Workflow

1. Import dataset
2. Data preprocessing
3. Feature and label separation
4. Splitting training and testing data
5. Training the model
6. Evaluating model accuracy
7. Making predictions

---

## 📊 Goal

The main goal of this project is to understand and implement a basic supervised machine learning classification model using real-world sonar signal data.
